Kerala, Slowly - travelogue website
Open index.html in a browser.

Add your own photos in the images/ folder with these exact names:
hero.jpg, kochi.jpg, munnar.jpg, thekkady.jpg, alleppey.jpg, varkala.jpg
Until you add them, the built-in illustrations (images/*.svg) are shown. A real photo with the same name replaces the illustration automatically.

Edit the text in index.html (stops, journal entries, food, tips) to match your own trip.
